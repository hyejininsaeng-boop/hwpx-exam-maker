# 한글(HWP) 수식 문법 요약 + 함정

## 함정 (실제로 겪은 것)
1. `4!=72` → `!=`가 **≠** 로 변환됨. `4!`=72` 처럼 `!` 뒤에 백틱.
2. `{a_{n}}^{2}` → 위첨자가 엉킴. **`a_{n}^{2}`** 로 쓴다.
3. 함수 이름 뒤에 띄어쓰기가 사라짐(`tan4x`, `lnxdx`). `tan` 4x`, `ln` x`dx` 처럼 백틱으로 간격을 준다.
4. `neq` 같은 영어 명령은 지원이 불확실 → `ne`.
5. 한글 단어는 수식 안에 넣지 않는다(폭 계산·글꼴이 어긋남). `T()` 로 분리(`content_sol.line_segs` 는 한글 덩어리를 자동 분리).
6. 수식 크기는 반드시 `sizes.py` 로 측정해서 넣는다(안 하면 잘림/겹침).
7. 소수점·퍼센트: `3.92`, `99 ``%`.
8. 괄호가 안 맞으면 수식 전체가 깨진다 → 출제 데이터를 받을 때 괄호·중괄호 짝을 검사한다.

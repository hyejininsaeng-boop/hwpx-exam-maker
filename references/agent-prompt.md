```
당신은 <시험명> 출제위원입니다. <과목> <문항 범위> 문항을 새로 만들어 주세요. 구성: <5지선다 번호·배점>, <단답형 번호·배점(정답은 0~999 정수)>.

## 반드시 지킬 것
- 기출을 베끼지 말고 완전히 새로운 문제(숫자·상황·문장 모두 새로). 형식(문제 틀)만 양식과 같게. 범위: <교육과정 범위>.
- 유형 가이드(양식과 같은 위치): <번호별 유형·배점·그림 유무>.
- 5지선다 선택지는 작은 값부터 큰 순서, 정답 번호가 ①~⑤에 고르게(최소 4종류). 오답은 그럴듯한 계산 실수 값.
- 모든 정답을 python(sympy/numpy/브루트포스, python -X utf8)으로 검증. 경우의 수·확률은 전수 계산. 조건이 모순되지 않는지, 답이 유일한지 확인. 단답 정답은 0~999 정수. 검증 요약을 보고.
- (그림 문항) 그림은 <figlib 설명>으로 직접 그려 PNG를 눈으로 확인(문제의 수치·위치 관계와 일치해야 함). 최종 데이터에는 PNG가 아니라 spec(딕셔너리)와 kind만.
- 파일은 <data 파일 경로> 하나만 새로 만든다. 그 밖의 파일은 읽기만(수정/삭제 금지).
```

## 받은 뒤 확인 (메인이 직접)
1. 데이터 파일을 `ast.parse` 로 읽어 문법 오류 확인, 수식 괄호·중괄호 짝 검사.
2. 정답 몇 개는 **다른 방법으로 직접 재계산**(특히 단답·고난도).
3. 빌드 후 PNG로 문항 문장·수식·그림이 정상인지 눈으로 확인.
4. 이상한 수식(`≠`로 변한 `!=`, 겹침 등)은 `references/equation-syntax.md` 함정 목록으로 고친다.

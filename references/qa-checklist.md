# 점검표 (납품 전)

## 내용
- [ ] 모든 문제가 새 문제인가(기출 문장·숫자·그림 그대로 남은 곳 없음, 안 쓰는 원본 그림 파일 제거됨)
- [ ] 정답이 계산으로 검증됐고, 일부는 다른 방법으로 한 번 더 확인됐는가
- [ ] 5지선다 선택지가 오름차순, 정답 번호가 고르게 분포
- [ ] 단답형 정답이 0~999 정수, 조건이 모순되지 않고 답이 유일
- [ ] 문제 번호·배점이 양식과 같은 위치/형식

## 모양 (render2.py 로 PNG 확인)
- [ ] 쪽 수·쪽/단 시작 문제가 양식과 같은 배치 (빈 쪽·넘침 없음)
- [ ] 수식이 잘리거나 겹치지 않음, `≠` 같은 엉뚱한 기호 없음
- [ ] 선택지 간격이 균등, 그림이 제 위치에 보이고 라벨이 문제와 일치
- [ ] 상자(조건·보기·증명) 줄바꿈 정상, "확인 사항" 상자 위치 정상
- [ ] 해설 포함 파일: 정답표 값, `1)` 형식 해설 번호, 풀이 수식 정상
- [ ] 바닥글 "현재 쪽 / 총 쪽수" 가 실제 쪽수와 맞음

## 파일
- [ ] 결과는 `.hwpx`만 지정 폴더에 저장 (PDF·임시 파일을 결과물로 두지 않음)
- [ ] 원본 `.hwp` 는 그대로, 작업 폴더의 스크립트·데이터 보존
- [ ] 재현 확인: `build_all.py` 대조 결과 "일치"
- [ ] 한글에서 직접 열어 인쇄 모양을 한 번 확인하도록 사용자에게 안내(자동 확인은 PDF 변환 결과 기준임을 밝힘)
